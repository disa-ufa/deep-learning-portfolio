# EduCompliance Copilot — безопасный RAG-ассистент для образовательной организации

**EduCompliance Copilot** — портфолио-проект нейро-сотрудника для сферы образования. Это не простой чат по PDF, а прикладной RAG-пайплайн с трассировкой, диагностикой галлюцинаций, улучшенным поиском и защитными ограничениями.

Проект помогает методистам, преподавателям и администрации быстро получать проверяемые ответы по вопросам цифровой дидактики, выбора образовательных технологий, качества онлайн-курса, security/privacy и AI-policy.

## Бизнес-идея

В образовательной организации много методических, нормативных и управленческих документов. Сотрудникам нужно быстро находить ответы, но обычная LLM может галлюцинировать, раскрывать служебные инструкции или обрабатывать недопустимые запросы.

**EduCompliance Copilot** решает эту задачу как безопасный нейро-сотрудник:

- отвечает только по базе знаний;
- показывает трассировку найденных фрагментов;
- сравнивает baseline RAG и RAG с постобработками;
- использует расширенный поиск Small-to-Big / LlamaPacks-style retrieval;
- блокирует небезопасные запросы через guardrails-слой.

## Что реализовано

### 1. RAG по PDF-книге

В качестве базы знаний используется открытая книга **Teaching in a Digital Age**. Ноутбук скачивает PDF, извлекает текст, разбивает его на чанки и строит embedding-индекс.

### 2. Трассировка RAG

Для каждого вопроса выводятся:

- исходные найденные чанки;
- финальные чанки после постобработок;
- размер prompt;
- контекст, который реально передаётся в LLM;
- ответ модели.

### 3. Постобработки для борьбы с галлюцинациями

Реализованы несколько улучшений:

- `score_cutoff` — отсев слабых совпадений;
- `keyword_boost` — усиление фрагментов с ключевыми словами;
- `sentence_window` — расширение найденного предложения соседним контекстом;
- `long_context_reorder` — перестановка фрагментов для лучшей работы LLM.

### 4. LlamaPacks-style advanced retrieval

Добавлен расширенный поисковик в стиле **Small-to-Big / Recursive Retriever**:

- поиск выполняется по маленьким `child chunks`;
- в prompt отправляются более крупные `parent chunks`;
- отдельно выводится трассировка child hits и выбранных parent chunks.

Такой подход снижает потерю смысла при разбиении документа на мелкие фрагменты.

### 5. Guardrails / безопасность

Настроен guardrails-слой для блокировки:

- prompt injection;
- раскрытия system prompt и hidden instructions;
- запросов персональных данных студентов;
- академической нечестности;
- запросов вне образовательного домена.

## Как запустить

1. Открыть ноутбук из папки `notebook/` в Google Colab.
2. Желательно включить GPU: **Среда выполнения → Сменить среду выполнения → T4 GPU**.
3. Запустить все ячейки сверху вниз.
4. Посмотреть таблицы трассировки:
   - baseline RAG;
   - postprocessed RAG;
   - Small-to-Big retrieval;
   - guardrails tests.

## Почему проект подходит для портфолио

Проект показывает не только умение «подключить LLM», а полный инженерный цикл разработки нейро-сотрудника:

1. продуктовая роль и системные инструкции;
2. база знаний и структура данных;
3. RAG-пайплайн;
4. трассировка и диагностика галлюцинаций;
5. улучшение retrieval;
6. безопасность и фильтрация запросов;
7. письменные выводы по результатам экспериментов.

## Ограничения

В демонстрационной версии используется лёгкая локальная LLM, чтобы ноутбук стабильно запускался в Colab без платных API-ключей. В промышленной версии модель можно заменить на контурную русскоязычную LLM, например AI Forever / SberDevices или другую современную instruct-модель.
